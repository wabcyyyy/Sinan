闭眼工匠

为什么 AI 生成的前端总有"模板味"，为什么换更好的工具也不解决——以及你今天就能用的第一个杠杆。

§1先说结论：问题不在你的技巧

你换了工具（Astra）仍不满意，这本身就是线索：换工具无效，说明瓶颈不在工具，在流程。默认的 vibe-coding 流程有一个结构性缺陷——AI 写代码，但从不看渲染出来的页面。

想象你雇了一位工匠，他闭着眼睛干活，做完也不睁眼检查。无论他手艺多好、你换多少位工匠，结果都一样：能用，但糙。你对前端的不满，绝大多数来自这批"需要眼睛才能发现"的问题：标题折行了、两张卡片没对齐、行距挤得喘不过气、按钮和输入框高度差 2px。

商业网站好看，也不是因为设计师天赋异禀——他们的工作 90% 是"看 → 调 → 再看"的循环。你缺的是这个环。好消息：这个环可以建，而且你一个人 + AI 就能建。

§2模板味的三个根因

根因一：均值回归

语言模型输出的是训练数据里平均水平的设计——千万个 Bootstrap 后台和 Tailwind 默认蓝的均值。商业网站好看，恰恰因为它们偏离均值：有人做过一连串明确的取舍（近黑按钮而不是蓝按钮、24px 卡片内边距而不是 10px、四档字号而不是一档）。

你不给取舍清单，模型只能给均值。这就是"模板味"的本质：没有人做过决定的地方，就是模板。

根因二：盲眼工匠

AI 看不见像素。它不知道你的行程卡片在 375px 宽的屏幕上标题换行了三行，不知道两个相邻模块的左边缘差了 8px，不知道浅灰字放在浅灰底上已经看不清。这些全都需要"渲染 → 截图 → 看"这个动作。没有它，AI 是在凭想象调样式；有它，每一次修改都有像素级的事实反馈。

根因三：形容词没有信息量

"优雅""高级""现代""有质感"——这些词在不同人脑中激活的画面完全不同，对模型也一样。你给形容词，它只能猜；而猜的默认方向永远是训练均值——绕回根因一。有效的输入是可测量的锚点：截图、具体字号、具体间距、色板约束、"对齐到这一条线"、"参照这个网站的这一块"。

你已经有家底 仓库根目录的 TREK-DESIGN-STYLE.md 是一份 563 行的取舍清单（色板 / 字号四档 / 间距节奏 / 组件规格都提好了）。第 2 课我们把它变成 AI 每次必读、甩不掉的约束——现在它只是一份"存在"的文档，还没进入你的日常循环。

③留白：内边距 10/12 → 20/22，行距 1.5 → 1.65，间距全部 4 的倍数
④信息分层：把"建议穿舒适鞋"从正文降级进 meta 行；把"删除"从三个并排按钮里拿掉（主次操作分离）
⑤轮廓：hairline 边框 + 轻阴影替代 1px 灰实线；圆角 6 → 14，与卡片体量匹配
⑥符号：去 emoji，用中点、箭头这类单色字符——色彩预算留给内容本身

把这 6 条逐个念一遍你会发现：没有一条需要美术功底。全部是可测量的参数。所谓设计感，就是一致地做对几十个这样的小参数，而不是灵感。

§5本课带走的东西：把形容词翻译成锚点

从今天起，对自己说"这页好丑"的时候，逼自己过一遍这五个问题——每题的答案都带数字或带指向（可打印版在 五问自检卡）：

  1. 层级：这一屏有几档字号？少于 3 档（正文/标题没拉开）通常就是"平"的来源。
  2. 留白：最挤的容器的内边距是多少 px？正文行高是多少？行高 1.5 以下、内边距 16px 以下，多半在喘不过气。
  3. 颜色：除黑白灰之外有几种彩色？超过 2 种主色通常在打架；accent 只该有一个。
  4. 对齐：同屏的卡片、文字、图标，左右边缘有没有压到同一条参考线？
  5. 密度：信息量与留白的比例，和对标产品（TREK）比是过疏还是过挤？

然后把答案写成指令。模板：「把 X 从 A 改成 B，参照 Y」。例："卡片内边距 12px → 20px，行高 1.5 → 1.65，参照 TREK-DESIGN-STYLE.md §4.1 的间距节奏。"

§6作业（10 分钟，下次 session 带回来）

  1. 打开司南任何一个你不满意的页面，截一张全屏图。
  2. 用 §5 的五问逐项过，把答案写下来（要带数字）。
  3. 挑出 3 条，改写成给 AI 的指令（用上面的模板）。指令里禁止出现"优雅 / 高级 / 质感 / 大气 / 现代"——每个要求必须能量出来，或指得出位置。
  4. 下次 session 带着这份清单来，我们当场改一轮，并把"截图 → 改 → 再截图"的闭环完整跑一遍。
