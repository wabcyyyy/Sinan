# Sinan 前端风格约束（一页版 · AI 生成 UI 前必读）

> 完整版与出处：仓库根 `TREK-DESIGN-STYLE.md`。本文件是压缩后的硬约束，供 AI 会话直接引用。
> 违反任何一条硬规则 = 返工。风格疑问以完整版为准。

## 气质一句话

冷静工具感 + 克制的玻璃质感。默认近乎单色，靠字体层级、圆角卡片、轻投影建立质感。反面教材：彩色 SaaS 模板味。

## 十条硬规则

1. **accent 只有一个**：近黑 `#111827`（dark 模式反转为 `#e4e4e7`）。禁品牌蓝/彩色主按钮。
2. **彩色预算**：除黑白灰外，颜色只允许出现在 status（success/danger/warning/info）chip 与地图 pin 按天着色。
3. **字号只用四档**：12（caption）/ 14（body）/ 18（subtitle）/ 24（title）。hero 大字另算。禁自造 13px/15px/16px。
4. **间距只用 4 的倍数**；卡片内边距 ≥ 20px。
5. **圆角**：小件 8 / 输入 10 / 卡片 12–16 / 大浮层 20–24 / pill 全圆。禁 4px 硬角。
6. **轮廓**：hairline 边框（`--border-*`）+ 双层轻阴影。禁粗灰实线、禁重阴影。
7. **图标**：lucide 线性 1.5–2px 描边，12–22px。禁 emoji 当图标、禁彩色 filled 拟物。
8. **行高**：正文 1.6–1.7，标题 1.2–1.4。正文行高 < 1.5 = bug。
9. **层级三档起步**：标题 600 / 正文 400 / 注释 12px 大写 + 0.14em 字距 + 最浅墨色。
10. **主次分离**：一屏一个实心主按钮；次操作 ghost；破坏性操作收进菜单，不与主操作并排。

## 组件速查

```
主按钮 : 近黑填充/白字/圆角 12 或 pill，px-5 py-2.5，press 缩放 0.97，150ms
次按钮 : hairline 描边/次级墨色/hover 浅灰底
卡片   : 白底/hairline 边/圆角 14/双层轻影/padding 20–24
chip   : 中性灰底/12px/pill/一个彩色只给 status
标签   : 11–12px/600/大写/0.14–0.18em 字距/最浅墨色
meta 行: 12px/最浅墨色/中点（·）分隔
空态   : 一行标题 + 一个动作，禁通用插画
动效   : 150–200ms / ease-out-quint；入场 fade-up 220ms；禁弹跳/旋转
```
