# AI 辅助 UI 设计 Resources

> 课程的 trusted sources。lesson 中的 knowledge 应来自这里，不来自模型的记忆。Gaps 一节列出还没找到的好资源，推动后续搜索。

## Knowledge

- [Article: "7 Rules for Creating Gorgeous UI (2024 update)" — Erik Kennedy, Learn UI Design](https://learnui.design/blog/7-rules-for-creating-gorgeous-ui-part-1.html)（[Part 2](https://learnui.design/blog/7-rules-for-creating-gorgeous-ui-part-2.html)）
  免费、写给"不会画画的人"的 UI 法则：光从上来、先做黑白、留白翻倍……。Use for: 建立判断"为什么丑"的词汇表。**lesson-0001 的 primary source**。
- [Book: *Refactoring UI* — Adam Wathan & Steve Schoger](https://www.refactoringui.com)
  Tailwind 作者写给开发者的 UI 战术手册（付费，~200 页，官网直购）。Use for: 逐组件的打磨战术，是 7 Rules 的系统化进阶。预算敏感可长期搁置，先吃透 7 Rules。
- [Article: "A Structured Workflow for Vibe Coding Full-Stack Apps" — Wasp, dev.to](https://dev.to/wasp/a-structured-workflow-for-vibe-coding-full-stack-apps-352l)
  结构化 vibe-coding：先地基后生成，避免混沌迭代。Use for: 把"设计约束前置"嵌进日常编码工作流。
- [本地文档: `TREK-DESIGN-STYLE.md`（仓库根目录）](../TREK-DESIGN-STYLE.md)
  用户自己从 TREK 4.2.1 源码提取的完整设计系统：token / 组件 / 动效 / 司南映射建议。Use for: 司南改版的单一参照，后续课程的主要教材之一。这是"参考驱动"路线的现成弹药。

## Wisdom (Communities)

- [r/vibecoding](https://www.reddit.com/r/vibecoding/) / [r/VibeCodeDevs](https://www.reddit.com/r/VibeCodeDevs/)
