# Vercel 个人展示版

展示构建复用正式 HomePage、ExplorePage、TripsPage、TripDetailPage、ChatPanel 和 MapLibre 页面。它不使用精简演示页面，也不连接 FastAPI、数据库或真实模型。

## 展示内容

- 首页“90秒体验局部修改”进入可跳过的三步引导：看第二天、发送固定调整指令、核对提案后保存。每次进入创建独立合成副本，保留已有演示编辑；正式模式免登录入口为 `/demo?tour=edit`。真实模型运行案例通过独立链接查看，不把固定样例当作模型实跑。
- 详情页桌面端时间线与工具栏并排，右侧切换地图、对话和待确认修改；手机端切换行程／地图／对话／修改预览，保留当前日期和草稿。
- 修改预览在原时间线上标记待移除、待调整条目，右侧展示提案；未确认时原行程与地图不变。“暂不应用”只收起预览，建议仍可重新打开，不表示服务端已撤销草稿。
- 费用变化仅比较提案涉及日期中有价格、可比较的人民币条目；按同行人数计算非住宿小计。缺价、外币或住宿变化时显示待核对，不推算节省额。保留说明仅覆盖提案未涉及的日期与住宿，不把部分字段相同当成所有内容都相同。
- 首页对话与信息确认、固定成都两人两天一晚的逐日交付、完成预览。
- 探索页的目的地、灵感与攻略，以及个人行程列表。
- 详情页每日时间线、地图点位与导航深链、预算、收藏、标题编辑。
- 对话输入“把第二天安排松一点”，先查看差异卡，确认后移除第二天的杜甫草堂；两人条目费用小计 1180 → 1080 元，第一天和住宿不变。小计不含未列出的交通费，所有单价均为样例估算。
- 演示行程和对话保存在当前标签页的 sessionStorage，刷新可续；重置体验恢复内置样例。与真实账号身份、草稿键隔离。

页面持续显示“产品交互演示 / 合成样例 / 不调用 AI”。其他城市的实时生成、其他自然语言编辑、分享、PDF、图片识别、语音转写和模型密钥配置需要真实后端；展示版不执行这些操作，不把固定结果冒充模型输出。地图底图仍依赖外网，失败时显示地图错误提示，行程和导航深链可继续使用。

## 时间取舍与恢复

2026-10-22 新增源码能力（未合并到生产分支前，公网旧版不包含本节入口）：详情页“时间不够？比较两种取舍”。

- 真实模式：选当天已有项目，标记固定原时段或可以舍弃，填写最早开始、截止时间、每次转场及返程预留。A 保留全部，B 仅移除明确可舍弃项；保留顺序和每项原时长，不做路线最优搜索、不新增地点、不查询模型或交通数据。已有必去／排除／时间要求继续校验，不能借此入口悄悄放宽。
- 两版展示结束时间、余量、移除项与可比的条目估价差。缺时长、固定时段冲突、越出窗口或违背既有要求时不可选择。转场／返程预留是用户输入的假设，不等于可赶上车；固定选择仅约束本轮比较与应用。
- 比较只读；选择时服务端按当前修订号重算并生成草稿，确认仍走既有归属、指纹与 CAS 校验。其他日期及住宿保留。版本列表支持二次确认恢复整个行程，事务内保存恢复前后快照、恢复需求并推进修订号；过期请求拒绝，快照失败整笔回滚。旧版本若没有记录需求，则保留当前需求，不声称可恢复当时未存储的信息。
- 展示模式：未修改的成都第 2 天，点击“载入返程取舍示例”。固定杜甫草堂 09:30–11:30，可舍弃咖啡与晚餐；16:00 截止、每次转场 30 分钟、返程再留 30 分钟。固定样例 A 18:00 结束、超时 150 分钟；B 15:00 结束、余量 30 分钟、已列条目估价少 230 元。选择后原行程仍不变，确认后小计 1180→950 元，恢复 V1 后回到原样。任意条件不会被这个样例冒充计算成功。

实际验收：桌面 1440×1000 固定演示已走比较、冲突禁用、草稿差异、确认、刷新和恢复。手机 390×844 使用真实 FastAPI 路由与隔离 SQLite 合成杭州行程，填写 12:15 截止／返程预留 15 分钟／转场 30 分钟，固定西湖、可舍弃午餐；服务端计算 A 超时 60 分钟、B 余量 30 分钟，完成草稿确认、刷新、恢复与再次刷新。没有真实模型调用；此记录证明交互和持久化链路，不证明旅行事实或 MySQL 并发性能。

## 条目直接修改、持久固定与就地撤销

条目可直接调整起止时间、移动日期或移除；住宿继续使用专门的住宿调整路径。新操作同事务保存修改前后版本，校验归属及修订号、使旧草稿失效，冲突失败整笔回滚。保存后的“撤销这次修改”恢复修改前快照；刷新后仍可从历史版本恢复。撤销携带当前修订号，不覆盖其他窗口后来保存的内容。

“固定安排”存于现有 `TripRequirements`，保留日期、原名、类型和时段；模型不能用拟变更需求清掉固定。解除必须在条目上显式操作，历史恢复会恢复当时的固定状态。固定不表示已预订或营业已核实。

真实模式可输入自然语言，先看提取的时间、预留和条目，再采用到表单、核对并比较。缺失信息不猜，未指定预留会标为建议值；含糊请求返回追问。识别阶段不产生草稿、不修改行程；比较本身仍为确定性计算。静态演示不开放任意自然语言理解。

本轮本地真实 FastAPI＋隔离 SQLite 合成账号已走固定、刷新、时间冲突拒绝、12:00→12:15 保存、就地撤销回 12:00。真实模型已将“9点半开始，12点半前结束，西湖时间不动，楼外楼午餐可以舍弃，每次转场留30分钟，返程留30分钟”提取为对应条件；这是单个解析样例，不是规划质量评测。相关测试另用假模型验证无副作用及非法条目 ID 拒绝。真实后端未部署。

本轮相关后端检查首次 123 项通过；新增解析检查批次触及 90 秒预算且出现失败，未记为通过，后续修正后的完整回归以当前提交 CI 为准。前端增量类型、主题、交互约定与相关单测通过；静态检查通过。

### 自动发布更新

启用 Git 集成并选择生产分支后，将通过验证的修改推送到该分支即可触发构建，成功后更新你的展示站。其他分支可用于预览，无需上传本地构建目录。

Vercel 项目设置：

| 设置 | 值 |
| --- | --- |
| Git repository | 你的 Sinan Fork |
| Production branch | 你的发布分支（默认 `master`） |
| Root Directory | `travel-frontend-react` |
| Framework | Vite |
| Build Command | `npm run build:demo` |
| Output Directory | `dist` |

`build:demo` 读取入仓的 `.env.demo`，其中仅含公开开关 `VITE_DEMO_MODE=true`。不需要数据库密码、JWT 或模型 Key，也无需购买域名。`.vercel/` 与 `.env.local` 是本机配置，不入仓。

在自己的 Vercel 项目部署列表中查看对应 Git 提交的状态。失败时检查日志，站点继续使用上一版成功部署；需要重试时在部署详情中使用 Redeploy。Git 集成需保留对所选仓库的授权。

发布成功后仍须验证公开 URL 和目标网络体验；构建通过本身不能说明浏览器交互或外部地图正常。

Vercel 官方说明：[Hobby 计划](https://vercel.com/docs/plans/hobby)、[Vite 与 SPA 路由](https://vercel.com/docs/frameworks/frontend/vite)。
